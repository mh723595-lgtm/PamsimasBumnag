# Dokumentasi fitur PAMSIMAS

Dokumen proposal-ready tersedia di [`Dokumentasi-Fitur-PAMSIMAS.docx`](Dokumentasi-Fitur-PAMSIMAS.docx).
Dokumen ini merangkum kemampuan yang diverifikasi pada source code cabang `main`.

Untuk membuat ulang DOCX setelah mengubah konten, jalankan dari root repository:

```sh
python3 docs/generate_dokumentasi.py
```

Generator hanya menggunakan pustaka standar Python dan menulis dokumen Word di folder `docs/`.
